# 素材源文件说明

站点的图片素材由学校官方发布的标识矢量文件提取生成。源 PDF 体积较大（地图约 13.5MB）且版权归学校所有，**不入 git 仓库**；从学校官方渠道获取后放到本地对应路径，运行提取脚本即可重新生成全部图片。

## 源文件 → 产物

| 源 PDF（本地） | 产物 | 用途 |
|---|---|---|
| `学校标识矢量文件/1 江苏大学校标.pdf` | `docs/public/img/emblem.svg` / `emblem.png` / `emblem-256.png` | 导航栏左上角圆形标志、浏览器标签页图标（favicon 为白圆底版） |
| `学校标识矢量文件/4 常用校标组合（横板）.pdf` | `docs/public/img/logo-horizontal.svg` / `.png` | **仅用于站点封面**（首页 hero 区） |
| `学校标识矢量文件/13 江苏大学校园地图（校本部）2021版.pdf` | `docs/public/img/campus-map.jpg`（4600px / q80） | [校园与学院分布](../docs/campus/map.md) |

## 使用约定

- **校徽（圆形）**：用于导航栏左上角圆形标志与浏览器标签页图标；深色模式下由站点 CSS 自动垫白色圆底以保证可读；
- **校标组合（横板）**：仅用于封面一处，不做其他扩展使用；
- **校园地图**：2021 版，部分学院已更名/调整，站内已标注"仅作方位参考"；待官方发布新版地图后更新。

## 重新生成

```bash
pip install pymupdf
python scripts/extract_assets.py
```
