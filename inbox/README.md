# 投稿箱（inbox）

往这个文件夹里**添加一个文件，就算投稿完成**。规则只有一条：把你的内容放进来。

- **格式随意**：Markdown、纯文本都行（Word / Pages 写的请把文字复制粘贴进来）；
- **文件名随意**：建议「主题-昵称」，例如 `考研-小明.md`；想匿名就别写昵称；
- **内容随意**：保研、考研、出国、就业、考公的经验，选课攻略，奖学金评定，美食探店……任何一件你觉得「当年要是有人告诉我就好了」的事。

投稿后会发生什么：

1. 维护者会定期整理投稿，归入手册对应章节（只做排版与归类，**不改动你的观点**）；
2. 你的名字会自动出现在手册的[感谢贡献者名单](https://ainzfn.github.io/UJS-Survival-Guide/appendix/contributors)；
3. 要求匿名就在文件开头写一句「匿名发布」，上架时将不署名。

**操作步骤**：进入本文件夹 → 右上角 **Add file → Create new file** → 文件名填 `主题-昵称.md` → 粘贴内容 → 拉到底点 **Commit changes**。完成。
