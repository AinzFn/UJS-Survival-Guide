## 建议大纲

1. **先想清楚为什么**——入党与选调、考公、部分岗位就业的关系（与[出路 · 选调与考公](/path/civil-service)互链）；不推荐"为了好处"而入，但应了解全流程再做决定；
2. **流程五阶段**——递交入党申请书 → 入党积极分子 → 发展对象 → 预备党员 → 正式党员，各阶段的条件、考察期与材料；
3. **时间线**——最早大一生效的申请、培养考察期大致多久（以学校党委及学院党务通知为准）；
4. **材料怎么写**——申请书、思想汇报、自传的要求与常见问题；
5. **常见问题**——支部活动频率、对绩点的影响、毕业时未转正怎么办。
