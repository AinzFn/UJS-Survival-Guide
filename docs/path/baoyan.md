## 综述部分建议大纲

1. **江大保研的基本规则**——推免名额怎么分（校级/院级）、绩点与综合测评的构成、加分项认定（竞赛、论文、专利），以最新推免工作文件为准，标注核实时间。现行的《推荐免试硕士研究生综合评价指标体系》（2021 下发，2026 年仍沿用）全文已收录在[学业生存 · 保研要求](/study/baoyan-requirement)；
2. **时间线**——从大一积攒条件到大三暑假夏令营、预推免、九月推免的完整节点表；
3. **保研率与去向**——历年数据（引用官方公开数据，标注年份）；
4. **常见问题**——边缘排名怎么办、夏令营怎么选、面试怎么准备。
