## 综述部分建议大纲

1. **出国读什么**——MS / PhD / 联合培养的区别与选择（参考交大手册"为了留学而出国"）；
2. **大学四年准备清单**——GPA、语言（TOEFL/IELTS/GRE）、科研/暑研、推荐信、文书；
3. **时间线**——从大二定方向到申请季的节点表；
4. **中介问题**——DIY 与找中介的利弊，如何辨别（参考交大手册"警惕出国中介"）；
5. **费用与奖学金**——CSC 及常见资助渠道；
6. **疫情后与当前的申请形势**——写作时注明"基于 XXXX 申请季观察"。

## 经验帖

按[经验分享模板](/contribute/writing-template)投稿至[经验分享合集](/path/experiences/)，文件名以 `[abroad]` 开头，格式参考：`[abroad]-2021-昵称.md`。

每篇应包含：基本背景（可模糊化）→ 申请结果（录取/拒信列表）→ 申请心得。**offer 与拒信都值得晒**——完整的申请结果列表比单一 offer 更有参考价值。
