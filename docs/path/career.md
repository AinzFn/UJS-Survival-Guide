## 综述部分建议大纲

1. **什么时候开始找实习**——按行业给出节奏（互联网秋招春招、制造业校招节奏、寒暑假实习窗口）；
2. **简历与作品**——各行业看重什么（成绩？竞赛？项目？实习经历？）；
3. **信息渠道**——校招系统、宣讲会、内推渠道；
4. **三方协议与违约**——签三方前必须懂的几件事；
5. **行业地图**——江大各专业毕业生常去的行业与公司类型（欢迎毕业生补充）。

## 经验帖

投至[经验分享合集](/path/experiences/)。

特别欢迎**已经在工作**的学长学姐写：
- 某个行业/岗位真实的工作日常与成长路径；

- 回头看：大学四年哪些准备最有用、哪些是徒劳。
