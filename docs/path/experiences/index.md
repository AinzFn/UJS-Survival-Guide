# 经验分享合集

这里收录历届同学的升学、求职经验帖，按去向与年份排列。**投稿方式见[如何投稿](/contribute/how-to-contribute)，写作模板见[写作模板](/contribute/writing-template)。**

## 命名规则

文件放在本目录，命名 `[去向]-入学年份-昵称.md`，去向缩写：

| 前缀 | 去向 |
|---|---|
| `[baoyan]` | 保研 / 推免 |
| `[kaoyan]` | 考研 |
| `[abroad]` | 出国（境）留学 |
| `[career]` | 就业 / 实习 |
| `[civil]` | 选调 / 考公 |
| `[other]` | 参军、支教、gap 等 |

示例：`[abroad]-2021- XiaoMing.md` ❌（有空格）→ `[abroad]-2021-xiaoming.md` ✅
