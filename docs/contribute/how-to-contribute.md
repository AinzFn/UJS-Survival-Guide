# 如何投稿

只需要一个 GitHub 账号（[注册入口](https://github.com/signup)，免费，两分钟），全程点鼠标，**没有方式二和方式三**。

## 投稿步骤

1. 打开仓库的**投稿箱**文件夹：[github.com/AinzFn/UJS-Survival-Guide/tree/main/inbox](https://github.com/AinzFn/UJS-Survival-Guide/tree/main/inbox)；
2. 点右上角 **Add file → Create new file**；
3. 文件名建议「主题-昵称」，例如 `考研-小明.md`（想匿名就不写昵称，并在开头注明「匿名发布」）；
4. 把内容粘贴进去，点上方 **Preview** 标签可预览排版；
5. 拉到页面底部点 **Commit changes**——完成。

【截图位：① inbox 文件夹与 Add file 按钮 ② 文件名与编辑区 ③ Commit changes 按钮——下批内容发布前补上】

## 投稿之后会发生什么

- 维护者定期整理投稿，归入手册对应章节（只做排版与归类，**不改动你的观点**），上架后网站自动更新；
- 你的名字自动进入[感谢贡献者](/appendix/contributors)名单；要求匿名则不署名；
- 想要文章更规整，可以参考各章节页面里现成的「建议大纲」和表格结构，但**格式完全不作要求**——内容永远比格式重要。

## 写什么都可以

- 经验类：保研 / 考研 / 出国 / 就业 / 考公的亲历（**失败复盘同样收**）；
- 攻略类：选课、竞赛、科研入门、评奖评优、办事流程；
- 生活类：美食探店、宿舍、镇江生活、兼职避坑；
- 以及任何一件你觉得「当年要是有人告诉我就好了」的事。

## 我们承诺

1. 只审合规、不改观点——不删减、不「平衡」你的真实体验；
2. 整理上架后 48 小时内在回帖或邮件中告知你（视渠道而定）；
3. 你随时可以要求更新或撤下自己的文章。
