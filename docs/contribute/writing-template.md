# 写作模板

三个模板，覆盖本手册几乎所有投稿类型。**复制粘贴，把「」里的内容替换掉即可。** 敏感信息（姓名、成绩、联系方式）按你的意愿模糊化或匿名。

---

## 模板一：专业介绍（写给没进这个专业的同学）

> 适合：本专业在读或毕业的同学。参考写法见[本章导读](/majors/)。文件放在 `docs/majors/你的学院/` 下，命名 `入学年份-昵称.md`。

```markdown
# 「专业名称」专业介绍（「入学年份」级 · 「昵称」）

> 最后核实于：2026-XX

## 这个专业学什么

「两三段：课程结构、从大一到大四的路线、和相近专业（如 XX）的区别」

## 优点

- 「基于你的真实体验，越具体越好」

## 缺点与坑

- 「同上。这是全文最有价值的部分——你当年入学前最想看到什么，就写什么」

## 什么样的同学适合/不适合

「性格、能力、出路偏好上的匹配建议」

## 给新生的三条建议

1. 「」
2. 「」
3. 「」

## 毕业去向参考

「本专业学长学姐常见的去向：保研/考研/出国的方向，就业的行业岗位」
```

## 模板二：经验分享类（保研 / 考研 / 出国 / 就业 / 考公等）

> 文件放在 `docs/path/experiences/` 下，命名 `[去向缩写]-入学年份-昵称.md`（如 `[baoyan]-2021-xxx.md`）。

```markdown
# [「去向缩写」]「入学年份」-「昵称」：「一句话概括结果，如 337 分上岸 XX 大学 XX 专业」

## 基本背景

「可按隐私需要模糊化，例如：」

- 专业 / 学院：
- 年级：
- 成绩排名：GPA 3.X / 4.0（专业前 X%）（可选）
- 语言成绩：（出国帖适用，可选）
- 科研 / 竞赛 / 实习经历：（择要）

## 申请 / 报考结果

「录取的写在前面并注明（接受/放弃），被拒的也可以列出来——完整的名单最有参考价值」

## 时间线

「按月份列出关键节点：什么时候定目标、什么时候开始复习/准备材料、考核/考试时间等」

## 经验与教训

「全文的核心。写你当时最需要但没人告诉你的事：如何选校/择校、资料与信息渠道、踩过的坑、如果重来一次会怎么做」

## 联系方式（可选）

「QQ / 微信 / 邮箱，愿意接受咨询就写，不愿意就删掉这一节」
```

## 排版小规范

- 中文标点用全角（，。：；），中英文之间加一个空格；
- 一级标题（`#`）留给文件标题，章节用二级（`##`）；
- 图片放 `docs/public/img/` 对应子目录，用绝对路径引用，如 `![说明](/img/campus-map.png)`；
- 文件名一律小写英文 + 连字符，禁止空格。
