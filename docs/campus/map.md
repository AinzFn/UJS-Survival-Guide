# 校园与学院分布

![江苏大学校本部地图（2021 版，点击可放大）](/img/campus-map.jpg)

::: warning ⚠️ 此图为 2021 版官方地图，仅作方位参考
学校院系近年有更名与调整，**图中标注的学院名称、部分楼栋功能已与现状不符**，请勿据图判断现有院系设置；新学院位置也请以实地和学校最新发布为准。

- **图源**：江苏大学党委宣传部《校园地图（本部）2021 版》（学校标识矢量文件提取）；
- **查楼技巧**：图内建筑有编号，左下角为编号索引表（按拼音分组），查楼号非常方便——如"三江楼 67 · G-4"表示在网格 G 列 4 行；
- 校园持续建设，发现与本页不符的变动，欢迎提 [Issue](https://github.com/AinzFn/UJS-Survival-Guide/issues) 或 PR 更新。
:::
