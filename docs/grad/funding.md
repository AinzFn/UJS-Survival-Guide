## 综述部分建议大纲

1. **研究生奖助体系总览**——国家助学金、学业奖学金、国家奖学的标准与覆盖率（引用学校最新文件，标核实时间）；
2. **三助岗位**——助研 / 助教 / 助管的申请方式、工作量与补贴实况；
3. **导师补贴**——各学院 / 课题组的普遍情况（写区间与事实，不点名）；
4. **评奖评优**——研究生奖学金的评定指标（科研成果、绩点、社工的权重）、时间线；
5. **经济规划**——学费 / 住宿 / 生活费的收支账，读研期间的合理预期。
