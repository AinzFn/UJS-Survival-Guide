# 科研生存

::: warning 🚧 综述等待编委撰写，经验帖征集中
:::

与本科阶段的[科研入门（大创、实验室）](/study/research)不同，这一页写的是**把科研当成日常和毕业条件**之后的事。

## 综述部分建议大纲

1. **文献**——检索工具、文献管理（Zotero 等）、怎么追一个方向的新进展；
2. **组会**——怎么准备汇报、被提问怎么应对、听别人组会能学到什么；
3. **写论文**——从复现到创新点、中英文学术写作入门、和导师改稿的正确姿势；
4. **投稿**——选期刊/会议、审稿周期、大修/被拒怎么处理、学术规范红线（一稿多投、署名、AI 使用）；
5. **心态与节奏**——科研不顺的常态、与同门互相支撑、什么时候该找导师或心理中心聊。
