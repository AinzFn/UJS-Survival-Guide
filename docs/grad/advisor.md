## 综述部分建议大纲

1. **开学前的信息搜集**——学院官网导师主页、往届学长学姐、研招群，哪些信号值得采信；
2. **导师类型盘点**——放养型 / 师徒型 / 大团队流水线，各自适合什么性格与目标（读博 / 就业 / 混学历）；
3. **双选会与首次见面**——聊什么、问什么：毕业要求、组会频率、补贴、工位、师兄师姐的去向；
4. **避坑信号**——哪些说法要当心（写事实与提问清单，不做导师评价）；
5. **进了组之后**——第一年怎么融入，方向不合适怎么沟通与调整。
