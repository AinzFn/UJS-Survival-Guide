::: tip 为什么这章最重要
本科生最大的信息差是选课，研究生最大的信息差是**选导师**——它几乎决定了你三年的科研方向、毕业进度、经济状况和心理状态。相关经验帖无论正面反面，都极其宝贵。
:::

::: tip 投稿提醒
- 研究生经验帖**不限结果**——顺利毕业的、延毕后走出来的、换了赛道离开的，都值得写；
- 涉及导师与课题组时，**以描述事实和自己的经历为主，避免人身攻击**，匿名投稿完全支持；
- 投稿方式见[如何投稿](/contribute/how-to-contribute)，在稿件开头标明「第五章 · 研究生生存」及署名方式。
:::
