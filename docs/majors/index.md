# 第五章 · 专业介绍

本手册的**众包核心区**：由各学院在读学生与毕业生写下的第一人称介绍——学什么、优缺点、给新生的建议。

::: tip 为什么这章最重要
官网的宣传材料不会告诉你一个专业的真实体验，而学长学姐的只言片语又太零碎。这一章就是把这些第一手判断集中起来：**报志愿、转专业、选方向之前**，先来这里看看别人的一手体验。
:::

## 如何投稿

1. 在下方学院列表中找到你的学院，进入对应文件夹；
2. 按[专业介绍模板](/contribute/writing-template#模板一-专业介绍-写给没进这个专业的同学)写一篇；
3. 文件命名 `入学年份-昵称.md`（如 `2023-xiaoming.md`），放到学院文件夹下；
4. 投稿方式见[如何投稿](/contribute/how-to-contribute)，支持网页投稿与邮箱匿名投稿。

同一个专业欢迎多篇投稿——**不同年级、不同去向、不同评价都有价值**，真实的手册应该是多声部的。
