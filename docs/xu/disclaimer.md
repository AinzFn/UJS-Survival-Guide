## 非官方声明

本手册由在校学生与毕业生**自发组织编写**，为非官方、非营利的学生互助项目。手册内容与江苏大学及各学院官方立场无关，不代表学校观点。

## 信息时效性

- 涉及政策的内容（保研细则、转专业门槛、评奖评优、办事流程等）**每年都可能变化**；
- 相关页面均应标注"最后核实于 XXXX-XX"，仅供检索方向参考，**一切以学校教务处、学工处及各学院发布的最新正式文件为准**；
- 发现内容过时请提 [Issue](https://github.com/AinzFn/UJS-Survival-Guide/issues) 或直接投稿修订。

## 内容原则

1. **写事实与亲身经历**。批评性内容（课程、专业、政策）须基于可核验的事实与作者亲历，就事论事，不进行人身攻击，不传播未经证实的信息；
2. **转载须授权**。引用站外内容（知乎、公众号等）必须获得原作者授权，并在文首注明出处与授权情况；
3. **隐私可选**。作者可对姓名、成绩、联系方式等敏感信息做模糊化或匿名处理，审核时会保护作者隐私；
4. **二次复核机制**。对某篇内容有异议，可在 Issue 区指出具体不实之处，维护者将邀请背景相似的同学进行二次复核并作出修改。
