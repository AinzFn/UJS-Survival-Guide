## 建议格式

每个食堂/档口一个小节：

```markdown
### XX 食堂

- **位置与开放时间**：
- **人均价格区间**：X ~ X 元
- **推荐档口**：什么菜值得吃，一句话点评
- **避雷提示**：
- **高峰期攻略**：几点去人少
- **最后核实于**：2026-XX
```

## 可以加分的内容

- 校外美食盘点（学校周边）——单独一节，注明消费区间；
- 「四年吃出来的私藏清单」类亲历帖；
- 配图（放 `docs/public/img/canteen/`，注意不要拍到他人正脸）。
